## Notes
* Bootstrap 5.3 uses a 12-column flexbox grid.
* Column widths are specified with `col-*` classes where `*` is 1–12.
* Responsive breakpoints: `xs` (default), `sm` (≥576px), `md` (≥768px), `lg` (≥992px), `xl` (≥1200px), `xxl` (≥1400px).
* `row-cols-*` sets a uniform column count on a row.
* Gutters are controlled with `g-*`, `gx-*`, `gy-*` utility classes.

## Column breakpoint reference

| Class | Breakpoint | Min width |
|---|---|---|
| `col-` | Extra small | `<576px` |
| `col-sm-` | Small | `≥576px` |
| `col-md-` | Medium | `≥768px` |
| `col-lg-` | Large | `≥992px` |
| `col-xl-` | X-Large | `≥1200px` |
| `col-xxl-` | XX-Large | `≥1400px` |

### Example #1 : Equal-width three columns

```twig
{% embed 'vartheme_bs5:grid' with {
  container_type: 'container',
  gutter: 'g-3'
} %}
  {% block content %}
    <div class="col"><div class="p-3 border rounded">Column 1</div></div>
    <div class="col"><div class="p-3 border rounded">Column 2</div></div>
    <div class="col"><div class="p-3 border rounded">Column 3</div></div>
  {% endblock %}
{% endembed %}
```

### Example #2 : Responsive stacked-to-horizontal

```twig
{% embed 'vartheme_bs5:grid' with {
```
