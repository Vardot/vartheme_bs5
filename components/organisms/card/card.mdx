## Notes
* The component supports multiple card layouts with image positions at top, left, right, and bottom.
* `content_vertical` controls vertical alignment for left and right image layouts.
* `media_ratio` is mainly useful for top and bottom image layouts.
* `has_padding` controls whether the card body includes inner spacing.
* Button output is only useful when both `url` and `button_label` are provided.
* Styling options such as `background` and `shadow` rely on Bootstrap utility classes.

## Examples

### Example #1 : Default card

```twig
{% include 'vartheme_bs5:card' with {
  orientation: 'image-top',
  heading_text: 'This is your card title',
  text: 'A short description goes here.',
  media: {
    src: '/components/organisms/card/assets/card-placeholder.svg',
    alt: 'Placeholder card image',
    width: 1200,
    height: 900
  },
  media_ratio: 'ratio-16x9',
  background: 'bg-body',
  shadow: 'shadow',
  has_padding: true
} %}
```
