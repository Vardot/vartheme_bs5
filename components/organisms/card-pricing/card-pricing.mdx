## Notes
* `badge_text` adds an optional badge label above the heading (e.g. "Most popular").
* `price`, `currency_symbol`, `currency_code`, and `symbol_position` combine to render the price display.
* `price_period` appears inline with the price (e.g. `/month`); `price_note` appears below.
* `text` accepts rich HTML — typically a `<ul>` features list.
* `show_features_divider` adds a border above the features section.
* `promote: true` highlights the card visually for the recommended plan.
* `button_url` and `button_label` must both be set for the CTA button to render.

## Examples

### Example #1 : Basic pricing card

```twig
{{ include('vartheme_bs5:card-pricing', {
  heading_text: 'Starter',
  level: 3,
  description: 'Good for small teams getting started.',
  price: '29',
  currency_symbol: '$',
  currency_code: 'USD',
  symbol_position: 'before',
  price_period: '/month',
  price_note: 'Billed monthly',
  text: '<ul><li>3 users</li><li>Email support</li><li>Basic reports</li></ul>',
  show_features_divider: true,
  shadow: 'shadow',
  border: 'border',
  background_color: 'bg-body',
  text_align: 'text-start',
  button_url: '/starter',
  button_label: 'Choose plan',
  button_variant: 'btn-primary'
}, with_context: false) }}
```
