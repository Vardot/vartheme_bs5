# Card Text

A lightweight text-only Bootstrap card with a single drag-and-drop content slot and no media area. Controls border, padding, background, shadow, corner style, equal height, and full-card stretched link.

- No media area — content slot is the only region
- `stretched_link` requires `link_url` to be set — makes the entire card clickable
- `padded: true` adds `p-4` to the content wrapper; when false, `p-0` is applied
- `equal_height: true` adds `h-100` for consistent heights in grid row layouts

> ### Bootstrap documentation
> - [Cards](https://getbootstrap.com/docs/5.3/components/card/)
> - [Stretched link](https://getbootstrap.com/docs/5.3/helpers/stretched-link/)
> - [Shadows](https://getbootstrap.com/docs/5.3/utilities/shadows/)

## Example

### Example #1 : Default text card

```twig
{% embed 'vartheme_bs5:card-text' with {
  card_border: true,
  background_color: 'bg-white',
  padded: true,
  box_shadow: 'shadow-sm',
  corner_style: 'rounded-3',
} %}
  {% block content %}
    <h3 class="h5 mb-2">Card text title</h3>
    <p class="mb-3">A simple text card for descriptions, highlights, or small content blocks.</p>
    <a href="#" class="btn btn-primary">Action</a>
  {% endblock %}
{% endembed %}
```

### Example #2 : Linked card

```twig
{% embed 'vartheme_bs5:card-text' with {
  card_border: true,
  background_color: 'bg-white',
  padded: true,
  box_shadow: 'shadow-sm',
  corner_style: 'rounded-3',
  stretched_link: true,
  link_url: 'https://example.com',
  link_target: '_blank',
} %}
  {% block content %}
    <h3 class="h5 mb-2">Clickable card</h3>
    <p class="mb-0">Entire card acts as a link.</p>
  {% endblock %}
{% endembed %}
```
