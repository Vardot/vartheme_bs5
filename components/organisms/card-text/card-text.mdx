## Slots
* `content`: Main text content area.

## Notes
* This is a minimal card component focused purely on textual content.
* `padded` adds internal spacing using Bootstrap utilities.
* `background_color` controls visual appearance.
* `stretched_link` enables full-card click behavior.
* `equal_height` helps align cards in grid layouts.

## Examples

### Example #1 : Default text card
```twig
{% embed 'vartheme_bs5:card-text' with {
  card_border: true,
  background_color: 'bg-white',
  padded: true,
  box_shadow: 'shadow-sm',
  corner_style: 'rounded-3'
} %}
  {% block content %}
    <h3 class="h5 mb-2">Card text title</h3>
    <p class="mb-3">Simple text card example.</p>
    <a href="#" class="btn btn-primary">Action</a>
  {% endblock %}
{% endembed %}
```

### Example #2 : Clickable card
```twig
{% embed 'vartheme_bs5:card-text' with {
  stretched_link: true,
  link_url: 'https://example.com',
  link_target: '_blank'
} %}
  {% block content %}
    <h3 class="h5 mb-2">Clickable card</h3>
    <p class="mb-0">Entire card acts as a link.</p>
  {% endblock %}
{% endembed %}
```
