## Notes
* Renders Drupal Views results as a Bootstrap table.
* `header` contains the column headers; `rows` contains the row data.
* Supports Bootstrap table modifiers: `table-striped`, `table-hover`, `table-bordered`, `table-sm`.
* `caption` adds an accessible caption element.
* Responsive wrapping can be enabled with the `responsive` property.
