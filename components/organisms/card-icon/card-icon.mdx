# Card Icon

Bootstrap card with an optional icon, heading, description, and optional link or button.

## Highlights

- Heading always renders as H3
- Optional icon
- Text alignment applies to the icon, heading, and description
- Background and shadow options use Bootstrap utility class values
- Natural card height
- Button mode or full-card link mode
- Padding checkbox that adds `p-4`
