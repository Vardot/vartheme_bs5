## Notes
* This component renders an optional Bootstrap icon, heading, description, and optional CTA button.
* The icon name should be passed without the `bi-` prefix.
* `text_align` affects the icon row, heading, and description alignment together.
* `has_padding` applies `p-4` to the card body.
* When both `url` and `button_label` are provided, the card renders a button.
* When only `url` is provided, the component can be used as a link-style card pattern depending on the surrounding implementation.

## Examples

### Example #1 : Default card icon
```twig
{% include 'vartheme_bs5:card-icon' with {
  text: 'Your heading here',
  description: '<p>This is placeholder text for a default card.</p>',
  icon: 'people',
  icon_size: 'fs-4',
  text_align: 'text-center',
  background_color: 'bg-body',
  shadow: 'shadow',
  has_padding: true
} %}
```
