## Example

### Example #1: Dark overlay with padded content
```twig
{% embed "vartheme_bs5:card-overlay" with {
  ratio: 'ratio-16x9',
  fit: 'object-fit-cover',
  padded: true,
  overlay_color: 'bg-dark',
  overlay_opacity: 'bg-opacity-50',
  h_align: 'text-start',
  v_align: 'align-items-end'
} %}
  {% block content %}
    <h3 class="card-title mb-2">Overlay title</h3>
    <p class="card-text mb-0">Overlay text goes here.</p>
  {% endblock %}
{% endembed %}
```

### Example #2: Whole-card clickable variant
```twig
{% embed "vartheme_bs5:card-overlay" with {
  stretched_link: true,
  link_url: 'https://example.com',
  link_target: '_blank',
  overlay_color: 'bg-primary',
  overlay_opacity: 'bg-opacity-50'
} %}
  {% block content %}
    <h3 class="card-title mb-2">Clickable card</h3>
    <p class="card-text mb-0">The full card is clickable.</p>
  {% endblock %}
{% endembed %}
```
