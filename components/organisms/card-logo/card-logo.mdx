# Card Logo

A simple logo card for displaying brand, partner, sponsor, and client logos. Renders a logo image centred inside a card body with auto height and optional full-card link behavior using Bootstrap's stretched-link.

- Logo image uses `object-fit-contain` so proportions are always preserved
- If `url` is provided, the entire card becomes clickable via a stretched link
- Card height is always auto — the card expands to fit the image naturally
- Uses Bootstrap utility classes only — no custom CSS required

> ### Bootstrap documentation
> - [Cards](https://getbootstrap.com/docs/5.3/components/card/)
> - [Stretched link](https://getbootstrap.com/docs/5.3/helpers/stretched-link/)
> - [Shadows](https://getbootstrap.com/docs/5.3/utilities/shadows/)

## Example

### Example #1 : Basic logo card

```twig
{{ include('vartheme_bs5:card-logo', {
  media: {
    src: '/components/foundation/images/assets/full-logo-dark.svg',
    alt: 'Partner logo',
    width: '600',
    height: '240'
  },
  shadow: 'shadow'
}, with_context: false) }}
```

### Example #2 : Linked logo card

```twig
{{ include('vartheme_bs5:card-logo', {
  media: {
    src: '/components/foundation/images/assets/full-logo-dark.svg',
    alt: 'Partner logo',
    width: '600',
    height: '240'
  },
  url: 'https://example.com',
  shadow: 'shadow-sm'
}, with_context: false) }}
```

### Example #3 : Logo card without shadow

```twig
{{ include('vartheme_bs5:card-logo', {
  media: {
    src: '/components/foundation/images/assets/full-logo-dark.svg',
    alt: 'Sponsor logo',
    width: '600',
    height: '240'
  },
  shadow: 'shadow-none'
}, with_context: false) }}
```
