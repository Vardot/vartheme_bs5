# Hero Card

A flexible Bootstrap 5 hero card for promotional sections, feature highlights, and call-to-action blocks. Supports seven media positions (overlay, start, end, top, bottom, content, none), optional edge-to-edge background, content alignment controls, configurable card border and padding, and a primary action button.

- `media_position: overlay` uses Bootstrap card overlay structure with a configurable color and opacity layer
- `media_position: start` or `end` creates a side-by-side split layout; gap is controlled via `split_gap`
- `bg_edge2edge: true` expands the background treatment to the outer wrapper beyond the container
- `media_slot` and `actions` slots allow full custom overrides for media (e.g. video) and button output

## Example

### Example #1 : Overlay hero

```twig
{% include 'vartheme_bs5:card-hero' with {
  title: 'Build faster with reusable components',
  heading_tag: 'h2',
  content_text: '<p>Create polished layouts with a flexible Bootstrap card structure.</p>',
  media: {
    src: '/path/to/image.jpg',
    alt: 'Hero image',
    width: 1200,
    height: 800
  },
  media_position: 'overlay',
  overlay_bg: 'bg-dark',
  overlay_opacity: 'opacity-50',
  content_color: 'text-white',
  button_1_label: 'Learn more',
  button_1_url: '/features',
  button_1_style: 'btn-primary',
  button_1_target: 'default'
} only %}
```
