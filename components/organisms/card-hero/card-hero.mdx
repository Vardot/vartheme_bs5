# Hero Card

A Bootstrap card component that supports five distinct media positions: overlay (media as background), start/end (side-by-side split), top/bottom (stacked), and a padded variant. Content and media are both passed as slots, making it suitable for use with Drupal render arrays.

- `media_position: overlay` places the image behind content using Bootstrap's `card-img-overlay` structure
- `media_position: start` or `end` creates a horizontal split layout
- `media_position: top` or `bottom` stacks media and content vertically
- Extra Bootstrap utility classes can be passed via `card_hero_utility_classes`, `card_hero_media_utility_classes`, and `card_hero_content_utility_classes` arrays

> ### Bootstrap documentation
> - [Cards](https://getbootstrap.com/docs/5.3/components/card/)
> - [Card image overlays](https://getbootstrap.com/docs/5.3/components/card/#image-overlays)

## Example

### Example #1 : Overlay card (default)

```twig
{% include 'vartheme_bs5:card-hero' with {
  card_border: false,
  padded: false,
  media_position: 'overlay',
  horizontal_alignment: 'start',
  vertical_alignment: 'end',
  card_hero_utility_classes: [],
  card_hero_media_utility_classes: [],
  card_hero_content_utility_classes: [],
  media: media,
  content: content,
} only %}
```

### Example #2 : Side-by-side split (media start)

```twig
{% include 'vartheme_bs5:card-hero' with {
  media_position: 'start',
  horizontal_alignment: 'start',
  vertical_alignment: 'center',
  media: media,
  content: content,
} only %}
```

### Example #3 : Padded overlay with utility classes

```twig
{% include 'vartheme_bs5:card-hero' with {
  media_position: 'overlay',
  padded: true,
  horizontal_alignment: 'center',
  vertical_alignment: 'center',
  card_hero_utility_classes: ['shadow'],
  card_hero_content_utility_classes: ['w-75'],
  media: media,
  content: content,
} only %}
```
