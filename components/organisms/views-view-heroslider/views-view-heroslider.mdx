## Notes
* Renders a Drupal Views result as a Bootstrap Carousel hero slider.
* `rows` contains the individual slide items rendered by Drupal Views.
* Supports autoplay, controls, and indicators via Bootstrap Carousel options.
* An empty `rows` array renders an empty slider placeholder.
