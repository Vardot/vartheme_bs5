## Notes
* The component displays hero content over a background image.
* `hero_slot` is a Twig slot/block.
* Content must be rendered using `{% block hero_slot %}`.
* `media` expects `src`, `alt`, `width`, and `height`.
* Layout is controlled by `container_type`, `bg_edge2edge`, `height`, `flex_position`, `overlay_bg`, `overlay_opacity`, `content_width`, and `object_position`.

## Examples

### Example #1 : Default hero billboard

```twig
{% embed 'vartheme_bs5:hero-billboard' with {
  container_type: 'container',
  bg_edge2edge: false,
  height: 'ribbon',
  flex_position: 'center-left',
  overlay_bg: 'bg-dark',
  overlay_opacity: 'opacity-50',
  content_width: 'w-100',
  object_position: 'center',
  media: {
    src: '/components/organisms/hero-billboard/assets/hero-bg-placeholder.svg',
    alt: 'Background image',
    width: 1920,
    height: 1075
  }
} %}
  {% block hero_slot %}
    <div class="text-white">
      <h2 class="display-5 mb-3">Hero billboard title</h2>
      <p class="lead mb-0">Add any rich content inside the hero slot.</p>
    </div>
  {% endblock %}
{% endembed %}
```
