# Hero Billboard

A full-width hero section with a background image, configurable overlay, flexible content positioning, and a rich hero slot. Designed for prominent page-top banners and campaign headers.

- Background image is rendered as a full-size cover layer behind an optional color overlay
- Content position (`flex_position`) controls both vertical alignment and horizontal text alignment simultaneously
- Overlay color and opacity are controlled independently via `overlay_bg` and `overlay_opacity` Bootstrap utility classes
- `hero_slot` accepts any markup — headings, paragraphs, buttons, and badges

> ### Bootstrap documentation
> - [Position](https://getbootstrap.com/docs/5.3/utilities/position/)
> - [Backgrounds](https://getbootstrap.com/docs/5.3/utilities/background/)
> - [Spacing](https://getbootstrap.com/docs/5.3/utilities/spacing/)

## Example

### Example #1 : Default billboard

```twig
{% embed 'vartheme_bs5:hero-billboard' with {
  container_type: 'container',
  bg_edge2edge: false,
  height: 'ribbon',
  flex_position: 'center-left',
  overlay_bg: 'bg-dark',
  overlay_opacity: 'opacity-50',
  content_width: 'w-100',
  object_position: 'center',
  media: {
    src: '/path/to/hero.jpg',
    alt: 'Hero background',
    width: 1920,
    height: 1075,
  },
} %}
  {% block hero_slot %}
    {% include 'vartheme_bs5:heading' with {
      heading_text: 'Hero Billboard Title',
      level: 2,
      text_size: 'display-5',
      text_color: 'text-white',
    } only %}
    <p class="lead mb-0 text-white">Add any rich content inside the hero slot.</p>
  {% endblock %}
{% endembed %}
```

### Example #2 : Centered hero with CTA buttons

```twig
{% embed 'vartheme_bs5:hero-billboard' with {
  container_type: 'container',
  height: 'large',
  flex_position: 'hero-center',
  overlay_bg: 'bg-black',
  overlay_opacity: 'opacity-75',
  content_width: 'w-75',
  media: {
    src: '/path/to/hero.jpg',
    alt: 'Hero background',
    width: 1920,
    height: 1075,
  },
} %}
  {% block hero_slot %}
    {% include 'vartheme_bs5:heading' with {
      heading_text: 'Build Bold Hero Experiences',
      level: 1,
      text_size: 'display-3',
      text_color: 'text-white',
      align: 'text-center',
    } only %}
    <p class="lead mb-4 text-white text-center">Compose headings, text, and actions inside the hero slot.</p>
    <div class="d-flex flex-wrap gap-2 justify-content-center">
      {% include 'vartheme_bs5:button' with { label: 'Primary action', variant: 'btn-primary' } only %}
      {% include 'vartheme_bs5:button' with { label: 'Learn more', variant: 'btn-light', outline: true } only %}
    </div>
  {% endblock %}
{% endembed %}
```
