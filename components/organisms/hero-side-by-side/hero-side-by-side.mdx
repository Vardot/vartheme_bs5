# Hero Side by Side

A split-layout hero section with an image column and a content column. Supports configurable image position, content alignment, background color, optional background image with overlay, and a CTA button.

- `image_position: left` reorders columns so the image appears on the start side
- Background color and content color are set independently — use `content_color: text-white` when using dark backgrounds
- Optional background image with overlay is separate from the main side image — controlled via `background_image`, `background_overlay_color`, and `background_overlay_opacity`
- Button is only rendered when both `button_label` and `button_url` are provided

## Example

### Example #1 : Default side-by-side hero

```twig
{{ include('vartheme_bs5:hero-side-by-side', {
  heading: 'Build better digital experiences',
  heading_level: 2,
  text: '<p>Create flexible, scalable Drupal experiences using modern components.</p>',
  image: {
    src: '/path/to/image.jpg',
    alt: 'Hero image',
    width: 1200,
    height: 900,
  },
  image_position: 'right',
  background_color: 'bg-white',
  content_color: 'text-dark',
  vertical_padding: 'py-4',
  button_label: 'Get started',
  button_url: 'https://example.com',
  button_variant: 'btn-primary',
}, with_context: false) }}
```

### Example #2 : Dark background with image on the left

{{ include('vartheme_bs5:hero-side-by-side', {

    height: 900,
  },
  image_position: 'left',
