## Slots
* `content`: Main card content area.

## Notes
* This component provides a stacked card with optional media shown above or below the content.
* `media_image` is the main image prop and is rendered through the shared image component.
* `ratio` and `fit` work together to control image cropping behavior.
* `padded` adds `p-4` to the content area.
* `stretched_link` only works when `link_url` is also provided.
* `equal_height` applies `h-100` to the card wrapper for grid consistency.

### Example #1 : Default impressed card
```twig

  box_shadow: 'shadow-sm',
  corner_style: 'rounded-3'
} %}
  {% block content %}

  {% endblock %}
{% endembed %}
```
