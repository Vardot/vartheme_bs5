# Group

Use the Group component to arrange content in a simple Bootstrap flex wrapper with spacing, alignment, wrapping, and background utilities.

## Highlights

- vertical or horizontal flow
- Bootstrap gap, alignment, and distribution utilities
- optional top, bottom, start, and end spacing utilities
- optional background color utility
