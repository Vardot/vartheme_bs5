## Slots
* `content`: Items rendered inside the group wrapper.

## Notes
* This component is a flexible Bootstrap wrapper for grouping items vertically or horizontally.
* `direction` switches between `flex-column` and `flex-row`.
* `wrap` only affects horizontal layouts.
* `gap`, alignment, padding, margin, and background are all passed through as Bootstrap utility classes.
* This component works well for button groups, tag clouds, stacked content, and small layout clusters.

## Examples

### Example #1 : Vertical stack
```twig
{% embed 'vartheme_bs5:group' with {
  direction: 'vertical',
  gap: 'gap-3'
} %}
  {% block content %}
    <div class="p-3 border rounded">First item</div>
    <div class="p-3 border rounded">Second item</div>
    <div class="p-3 border rounded">Third item</div>
  {% endblock %}
{% endembed %}
```

### Example #2 : Horizontal actions
```twig
{% embed 'vartheme_bs5:group' with {
  background_color: 'bg-light',
  direction: 'horizontal',
  gap: 'gap-2',
  wrap: 'wrap',
  align_items: 'align-items-center',
  justify_content: 'justify-content-start',
  padding_block_start: 'pt-3',
  padding_block_end: 'pb-3',
  padding_inline_start: 'ps-2',
  padding_inline_end: 'pe-2'
} %}
  {% block content %}
    <button class="btn btn-primary">Save</button>
    <button class="btn btn-outline-secondary">Preview</button>
    <button class="btn btn-link">Cancel</button>
  {% endblock %}
{% endembed %}
```
