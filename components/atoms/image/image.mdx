## Notes
* The component prefers `dynamic-responsive-image` when available, and falls back to `canvas:image` (both included with `ignore missing`).
* `media.data` can be provided when integrating with `drimage_improved`.

## Examples

### Example #1: Default image
```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/components/atoms/image/assets/image-placeholder.svg',
    alt: 'Placeholder image',
    width: 1200,
    height: 800,
  },
} only %}
```

### Example #2: 16:9 ratio crop + cover
```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/components/atoms/image/assets/image-placeholder.svg',
    alt: 'Wide image',
    width: 1200,
    height: 800,
  },
  ratio: 'ratio-16x9',
  fit: 'object-fit-cover',
  width: 'w-75',
  align: 'mx-auto',
  rounded: 'rounded-1',
} only %}
```

### Example #3: Linked image (new tab)
```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/components/atoms/image/assets/image-placeholder.svg',
    alt: 'Linked image',
    width: 1200,
    height: 800,
  },
  link_url: 'https://example.com',
  target: 'blank',
} only %}
```
