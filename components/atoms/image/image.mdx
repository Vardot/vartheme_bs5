# Image

A responsive Bootstrap image component with optional aspect-ratio cropping, object-fit control, alignment, sizing, border radius, and an optional link wrapper. Supports both native `<img>` rendering and `drimage_improved` responsive images when available.

- `ratio` wraps the image in a Bootstrap `.ratio-*` box for consistent cropped shapes — set `fit` to `object-fit-cover` or `object-fit-contain` to control how the image fills that box
- `rounded` accepts the full set of Bootstrap border-radius utilities — use `none` to apply no radius
- When `drimage_improved` data is available via `media.data`, the component renders a responsive `<picture>` element; otherwise it falls back to a plain `<img>`

## Example

### Example #1 : Default image

```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/path/to/image.jpg',
    alt: 'Image description',
    width: 1200,
    height: 800,
  },
} only %}
```

### Example #2 : 16:9 ratio with cover crop

```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/path/to/image.jpg',
    alt: 'Wide image',
    width: 1200,
    height: 800,
  },
  ratio: 'ratio-16x9',
  fit: 'object-fit-cover',
  width: 'w-75',
  align: 'mx-auto',
  rounded: 'rounded-1',
} only %}
```

### Example #3 : Linked image opening in a new tab

```twig
{% include 'vartheme_bs5:image' with {
  media: {
    src: '/path/to/image.jpg',
    alt: 'Linked image',
    width: 1200,
    height: 800,
  },
  link_url: 'https://example.com',
  target: 'blank',
  width: 'w-50',
  align: 'mx-auto',
} only %}
```
