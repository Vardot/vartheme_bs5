## Notes
* Renders an `<input type="submit">` with Bootstrap button styling.
* `variant` maps to Bootstrap button classes (e.g. `btn-primary`, `btn-secondary`).
* `disabled` adds the disabled attribute and visual state.

## Examples

### Example #1 : Primary submit button

```twig
{{ include('vartheme_bs5:input-submit', {
  value: 'Submit',
  variant: 'btn-primary'
}, with_context: false) }}
```

### Example #2 : Secondary submit button

```twig
{{ include('vartheme_bs5:input-submit', {
  value: 'Save changes',
  variant: 'btn-secondary'
}, with_context: false) }}
```
