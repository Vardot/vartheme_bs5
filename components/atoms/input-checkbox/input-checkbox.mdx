## Notes
* Renders a Bootstrap checkbox input with label.
* `checked` sets the default checked state.
* `disabled` renders the checkbox and label in a disabled state.
* `required` adds the HTML required attribute.

## Examples

### Example #1 : Basic checkbox

```twig
{{ include('vartheme_bs5:input-checkbox', {
  id: 'agree',
  label: 'I agree to the terms',
  name: 'agree',
  checked: false,
  required: true
}, with_context: false) }}
```

### Example #2 : Pre-checked disabled checkbox

```twig
{{ include('vartheme_bs5:input-checkbox', {
  id: 'newsletter',
  label: 'Subscribe to newsletter',
  name: 'newsletter',
  checked: true,
  disabled: true
}, with_context: false) }}
```
