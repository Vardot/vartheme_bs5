# Icon

Renders a Bootstrap Icon using the `vartheme_bs5:bootstrap-icon` component. Supports selecting from a curated list of Bootstrap Icons, with size and color controlled via Bootstrap utility classes.

- `icon` accepts any icon name from the predefined list — omit the `bi-` prefix
- `icon_size` uses Bootstrap's `fs-1` through `fs-6` font-size scale (`fs-1` is largest)
- `color` uses Bootstrap text color utilities such as `text-primary`, `text-danger`, or `text-muted`
- If `icon` is not provided, the component renders nothing

> ### Bootstrap documentation
> - [Icons](https://icons.getbootstrap.com/)
> - [Font size utilities](https://getbootstrap.com/docs/5.3/utilities/text/#font-size)
> - [Color utilities](https://getbootstrap.com/docs/5.3/utilities/colors/)

## Example

### Example #1 : Default icon

```twig
{% include "vartheme_bs5:icon" with {
  icon: 'people',
  icon_size: 'fs-4',
  color: 'text-body',
} %}
```
