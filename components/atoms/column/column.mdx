# Column

A minimal Bootstrap `.col` wrapper for use inside the Row component. It exposes a single content slot and applies no width, spacing, or style settings of its own — all layout control is delegated to the parent Row.

- Renders a plain `.col` div with no additional classes
- Column width is controlled by the parent Row using `row-cols-*` or explicit Bootstrap column classes on the wrapper
- Use `{% embed %}` to inject content via the `content` slot

> ### Bootstrap documentation
> - [Grid system](https://getbootstrap.com/docs/5.3/layout/grid/)
> - [Columns](https://getbootstrap.com/docs/5.3/layout/columns/)

## Example

### Example #1 : Single column

```twig
{% embed 'vartheme_bs5:column' %}
  {% block content %}
    <div class="p-3 border rounded bg-light">Column content</div>
  {% endblock %}
{% endembed %}
```

### Example #2 : Two columns inside a row

```twig
<div class="container py-4">
  <div class="row g-3">
    <div class="col-md-6">
      {% embed 'vartheme_bs5:column' %}
        {% block content %}
          <div class="p-3 border rounded bg-light">First column</div>
        {% endblock %}
      {% endembed %}
    </div>
    <div class="col-md-6">
      {% embed 'vartheme_bs5:column' %}
        {% block content %}
          <div class="p-3 border rounded bg-body-secondary">Second column</div>
        {% endblock %}
      {% endembed %}
    </div>
  </div>
</div>
```
