# Heading

Renders an HTML heading (`h1`–`h6`) with optional Bootstrap typography utilities and an optional linked heading via the `vartheme_bs5:link` component.

- `level` controls the semantic HTML tag (`h1`–`h6`)
- `text_size` overrides the visual size independently of the semantic level using Bootstrap heading or display classes
- `text_color`, `align`, `font_weight`, and `font_style` apply Bootstrap utility classes to the heading element
- When `url` is provided the heading text is rendered as a link; set `target` to `_blank` to open in a new tab

> ### Bootstrap documentation
> - [Typography – Headings](https://getbootstrap.com/docs/5.3/content/typography/#headings)
> - [Typography – Display headings](https://getbootstrap.com/docs/5.3/content/typography/#display-headings)
> - [Utilities – Text](https://getbootstrap.com/docs/5.3/utilities/text/)

## Examples

### Example #1: Simple H2

```twig
{% include 'vartheme_bs5:heading' with {
  heading_text: 'Hello world',
  level: 2,
} only %}
```

### Example #2: Display heading, centered, colored

```twig
{% include 'vartheme_bs5:heading' with {
  heading_text: 'Big title',
  level: 2,
  text_size: 'display-3',
  align: 'text-center',
  text_color: 'text-primary',
  font_weight: 'fw-bold',
  font_style: 'fst-italic',
} only %}
```

### Example #3: Linked heading (opens in a new tab)

```twig
{% include 'vartheme_bs5:heading' with {
  heading_text: 'Read more',
  level: 3,
  url: 'https://example.com',
  target: '_blank',
} only %}
```
