# Plain Text

A minimal plain text component with optional trim behavior.

> ### Bootstrap documentation
> * https://getbootstrap.com/docs/5.3/content/typography/
> * https://getbootstrap.com/docs/5.3/content/typography/#inline-text-elements
> * https://getbootstrap.com/docs/5.3/utilities/api/

## Properties
<Controls />

## Notes
* This component renders plain text content safely
* No HTML rendering (escaped output)
* Ideal for user/admin input where HTML is not allowed
