# Row

The Row component is a Bootstrap grid row wrapper for Drupal. It helps you build responsive layouts with optional container wrapping, row column presets, alignment controls, background utilities, and spacing utilities.

## Best uses

- Multi-column content sections
- Card grids
- Feature rows
- CTA rows with controlled spacing
- Full-width background wrappers with inner containers

Use Bootstrap column markup inside the `content` slot for best results.
