Use the Section component to create consistent layout wrappers with Bootstrap containers, spacing utilities on all four sides, background options, and responsive column presets.

## Highlights

- 1 to 6 column presets
- optional header and footer regions
- optional background image with overlay
- Bootstrap-based spacing, container, color, and shadow utilities
